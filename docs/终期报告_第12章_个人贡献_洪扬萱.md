## 12.X 洪扬萱 — 个人贡献声明

本人在 JobBridge Tech Team 中担任 **Development Specialist（平台开发负责人）**，自项目启动以来负责 GBA-VEEP 网站的整体建设与迭代，主要贡献如下。

**双端门户与共享组件。** 本人主导搭建个人端（21 页）与企业端（8 页）多页网站，完成首页角色分流、门户导航，以及登录、捐款、法律援助、多语言等共享组件封装，使双端交互一致、减少重复开发。中期完成的基础架构，在终期落实为覆盖匹配、投递、面试、法律等全部业务场景的可访问页面。

**核心业务后端。** 本人负责 Node 业务服务及关键模块：注册登录与 JWT 认证、画像与弱势群体类型推断、企业组织与多 HR 协作、岗位发布/匹配/投递、捐款与访问权限、法律援助全流程、面试邀约与看板回写等，配合数据库多轮结构升级，构成网站稳定运行的业务底座。

**岗位供给与 AI 嵌入。** 本人开发残联公开岗位爬虫及定时调度，将外部友好岗位与企业自建岗位一并纳入匹配池；并完成 Node 与 Python AI 服务的接口衔接，包括统一验签、简历同步至业务库、评估面试得分回写，使 AI 简历、模拟/评估面试、学习路径嵌入网站主流程而非孤立存在。

**部署与联调保障。** 本人完成 Docker 与 Nginx 配置，支持本地分服务调试与容器化演示；参与技能匹配评分、免捐策略、企业端应聘者优先排序等规则验证，并根据多轮联调与答辩反馈修正页面流程、接口细节及空状态提示，保障终期现场演示稳定可用。

综上，本人贡献集中于 **网站从可演示原型到功能完整就业赋能平台的工程实现**，涵盖前端双端、业务后端、爬虫、部署与 AI 联调。本人声明以上内容真实准确，愿在答辩与评审中进一步说明。
