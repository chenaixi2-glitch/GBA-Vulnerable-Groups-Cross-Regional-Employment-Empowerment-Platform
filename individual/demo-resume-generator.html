PDF, DOCX, TXT, MD supported — max 10MB per file

Supported formats

  • PDF (.pdf) — recommended; text-based PDFs parse best
  • Word (.docx) — new format only, not legacy .doc
  • Plain text (.txt) and Markdown (.md)

Not supported: image files (.jpg/.png), legacy Word (.doc), scanned-only resumes (OCR to text or PDF first)

How photos in resumes are handled

  • The system extracts text only — it does not pull ID photos from PDF/Word
  • For Chinese resumes, upload an ID photo in «Resume Analysis Results» (recommended for SOE/public sector)
  • For English resumes, Western norms apply — output has no photo
  • With blind screening enabled, recruiters won't see photo, age, or gender in the first review
